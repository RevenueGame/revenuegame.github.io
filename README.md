# Revenue Game · Vrai ou Bullshit ?

Site de la newsletter LinkedIn **Revenue Game** d'Antonin Cotte : le jeu hebdomadaire « Vrai ou Bullshit ? » et l'archive des éditions.

- `index.html` : tout le site (le contenu est dans le bloc JSON entre `/*DATA:START*/` et `/*DATA:END*/`).
- `data/vivier.json` : réserve de faits sourcés pour les prochaines grilles.

Publié avec GitHub Pages.
